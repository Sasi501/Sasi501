# `04` — PhishGuard Architecture

One of the systems I'm most interested in building is **multimodal security intelligence**.

```text
                         ┌───────────────────────┐
                         │      WEBSITE / URL     │
                         └───────────┬───────────┘
                                     │
                    ┌────────────────┼────────────────┐
                    │                │                │
                    ▼                ▼                ▼
              ┌──────────┐     ┌──────────┐     ┌──────────┐
              │   URL    │     │   TEXT   │     │  VISUAL  │
              │ ANALYSIS │     │ ANALYSIS │     │ ANALYSIS │
              └────┬─────┘     └────┬─────┘     └────┬─────┘
                   │                │                │
                   ▼                ▼                ▼
              CatBoost /        DistilBERT       EfficientNet
               XGBoost
                   │                │                │
                   └────────────────┼────────────────┘
                                    ▼
                           ┌──────────────────┐
                           │ ENSEMBLE ENGINE  │
                           └────────┬─────────┘
                                    │
                                    ▼
                           ┌──────────────────┐
                           │ THREAT / RISK    │
                           │     SCORE        │
                           └────────┬─────────┘
                                    │
                                    ▼
                           ┌──────────────────┐
                           │ XAI EXPLANATION  │
                           └──────────────────┘
```

**The idea:** don't rely on one signal.

Combine **URL behavior + language + visual evidence** to make a stronger security decision.
